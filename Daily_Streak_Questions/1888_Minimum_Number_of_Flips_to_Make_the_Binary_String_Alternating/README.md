<h2><a href="https://leetcode.com/problems/minimum-number-of-flips-to-make-the-binary-string-alternating">1888. Minimum Number of Flips to Make the Binary String Alternating</a></h2><h3>Medium</h3><hr><p>You are given a binary string <code>s</code>. In one operation, you can choose any character and flip it from <code>'0'</code> to <code>'1'</code> or from <code>'1'</code> to <code>'0'</code>.</p>

<p>Return the minimum number of operations required to make <code>s</code> alternating.</p>

<p>&nbsp;</p>

<p><strong class="example">Example 1:</strong></p>

<pre>
<strong>Input:</strong> s = "111000"
<strong>Output:</strong> 2
</pre>

<p><strong class="example">Example 2:</strong></p>

<pre>
<strong>Input:</strong> s = "010"
<strong>Output:</strong> 0
</pre>

<p><strong class="example">Example 3:</strong></p>

<pre>
<strong>Input:</strong> s = "1110"
<strong>Output:</strong> 1
</pre>

<p>&nbsp;</p>

<p><strong>Constraints:</strong></p>

<ul>
<li><code>1 ≤ s.length ≤ 10<sup>5</sup></code></li>
<li><code>s[i]</code> is either <code>'0'</code> or <code>'1'</code>.</li>
</ul>
